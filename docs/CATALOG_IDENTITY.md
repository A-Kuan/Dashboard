# SKU 资料库身份与权限接入

## 当前安全边界

开发环境使用免登录身份，并允许在界面中切换角色做验收。每个开发角色拥有独立的稳定操作人 ID，因此可以验证“提交人不能审核自己的方案”。

生产环境默认是 `anonymous-readonly`：即使客户端伪造操作人名称或管理员角色，请求也只会得到只读权限。不要为了临时联调直接开启生产身份信任。

## 可信身份桥合同

生产写入只有在以下条件同时满足时才会启用：

1. API 进程配置 `TRUST_PROXY_IDENTITY=1`。
2. API 进程通过受保护的 EnvironmentFile 配置高强度 `TRUST_PROXY_IDENTITY_SECRET`。
3. 身份网关覆盖所有外部传入的 `x-operator-*`、`x-identity-provider` 和 `x-catalog-identity-secret` 请求头，不得透传浏览器提供的值。
4. 身份网关向 API 注入与服务端一致的 `x-catalog-identity-secret`。
5. 请求包含稳定且非空的 `x-operator-id`、显示名 `x-operator-name` 和系统支持的 `x-operator-role`。

身份网关注入的请求头：

| 请求头 | 用途 |
| --- | --- |
| `x-operator-id` | 企业身份系统中的稳定用户 ID，不使用姓名或邮箱代替 |
| `x-operator-name` | 界面和审计记录中的显示名；必须是 UTF-8 百分号编码后的 ASCII 字符串 |
| `x-operator-role` | `catalog_viewer`、`catalog_editor`、`catalog_reviewer` 或 `catalog_admin` |
| `x-operator-email` | 可选，仅用于身份展示与后续通知 |
| `x-identity-provider` | 身份来源，例如企业 SSO 名称 |
| `x-catalog-identity-secret` | 身份网关与 API 的共享密钥，绝不能下发给浏览器 |

共享密钥不匹配、身份字段缺失、角色无效或未启用信任时，API 一律回退为匿名只读，不接受部分身份。

`x-operator-name` 例如“管理员甲”应注入为 `%E7%AE%A1%E7%90%86%E5%91%98%E7%94%B2`，避免非 ASCII 字符直接进入 HTTP 请求头。无法解码的显示名会被视为无效身份。

## 迁移职责分离

| 角色 | 迁移能力 |
| --- | --- |
| 资料录入 | 创建迁移方案、修正字段、记录排除原因 |
| 资料审核 | 批准或退回方案；迁移完成后要求整改或独立验收，不能审核自己提交的方案 |
| 资料管理员 | 可创建、审核他人方案，并在批准后正式执行迁移；不能验收自己执行的批次 |
| 只读查看 | 只查看预览、方案与审计轨迹 |

迁移方案会记录提交、批准、退回、开始执行、执行完成、执行失败、要求整改和验收通过事件。每条事件包含稳定用户 ID、显示名、角色、身份来源、时间和必要的上下文。验收通过前，系统会动态检查整个迁移批次生成的 SKU 是否完成适配专项审核和 SKU 审核；验收后若目标资料版本发生变化，报告会标记漂移。

## 上线检查

身份网关接入应先在独立预发布入口完成以下验证，再配置生产 EnvironmentFile：

- 浏览器直接伪造管理员请求头仍返回 403。
- 密钥错误、缺少用户 ID、未知角色均返回匿名只读会话。
- 资料员可以提交方案，但不能审核或执行。
- 审核员可以审核他人方案，但不能执行。
- 管理员不能审核自己提交的方案。
- 管理员可以执行由其他身份批准的方案。
- 执行人不能验收自己的迁移批次；审核员可以要求整改，但只有整批目标 SKU 全部核验通过时才能验收。
- `/api/v2/catalog/session` 返回正确的 `id`、`authenticated`、`authMode` 和 `identityProvider`。
- 审计事件中的用户 ID 与身份系统记录一致。

完成以上检查前，生产保持匿名只读，不创建真实迁移方案。
