# 导航组件约定

## 参考与范围

用户选定的导航参考保存在 [references/sidebar-reference.png](references/sidebar-reference.png)。它是一张带注释的设计说明图，右侧英文说明、虚线框和外部引导线不属于产品界面。

采用其白色圆角容器、灰色线条图标、浅灰选中底色、分组折叠和弧形子项连接线。应用名称继续使用 Dashboard；采用 Tabler 的布局图标作为通用应用图标，不复制参考图的 Brainwave 品牌标识。

当前只接入“工作台 → 首页”。没有照搬参考图的设计、素材、收藏、文件夹业务，也没有虚构数量。首页与 404 的主内容仍保持最小骨架。

## 结构

- `src/components/navigation/Sidebar.tsx`：公共导航、递归菜单、移动端开关。
- `src/components/navigation/types.ts`：分区、分组、链接的类型。
- `src/config/navigation.ts`：唯一的菜单配置入口。
- `src/components/navigation/sidebar.css`：仅作用于 `.sidebar` 内的样式。
- `src/components/layout/layout.css`：承载导航的两列布局与小屏单列布局。

## 配置

`NavigationSection` 提供可选的分区标题。菜单项分为 `group` 与 `link`：

- `id` 必须在所属列表内唯一，`label` 是可见名称。
- 分组包含 `children`，可通过 `defaultOpen` 指定初始展开状态。
- 链接提供 `to`，默认为完整路径匹配；父路径匹配可显式设置 `end: false`。
- `icon` 是 Tabler 图标组件，按需导入。
- `badge` 是可选数字，仅在有真实数量时传入；未传入时不显示。

后续菜单名称在配置中修改。新增真实业务页面时，还需同步添加路由并更新架构文档；不要添加指向不存在页面的业务菜单。

## 视觉

- 桌面栏宽 280px，外边距 24px，圆角 28px。
- 白色底，正文 #191919，图标及次级文字 #808080，选中底色 #f0f0f0。
- 行高至少 52px，行圆角 15px，正文 15px，线条图标 22px。
- 子级缩进与弧形连接线使用 CSS 边框表达层级关系；它们不是自绘图标或品牌素材。
- 当前路由的上级分组以浅灰底突出，子项以深色字重突出，与参考图层级保持一致。
- 颜色变量集中在 sidebar.css 的 `.sidebar` 中，不建立全局主题系统。

## 交互与可访问性

- 分组使用原生按钮，点击、Enter、Space 都可展开或收起；通过 aria-expanded 与 aria-controls 关联子列表。
- 当前链接由 NavLink 输出 aria-current。Tab 按顺序聚焦可见按钮和链接；收起的子菜单不会接收焦点。
- 在展开的分组内按 Escape 会收起该分组并将焦点移回分组按钮。
- 720px 及以下采用顶部面板；菜单默认收起，通过带标签的按钮展开。点击链接后收起手机端菜单；Escape 可关闭手机菜单。
- 手机菜单采用文档内展开，不使用覆盖层或焦点锁定。
- 展开状态为本次挂载的内存状态，刷新后恢复初始配置；没有浏览器存储或服务端请求。
- 聚焦边框、悬停与选中反馈齐备；尊重减少动态效果偏好。

## 扩展边界

导航本身不实现权限控制、文件夹创建或业务数据统计。需要这些能力时按真实业务逐步增加，同时更新本文件。视觉检查记录见仓库根目录 design-qa.md。
