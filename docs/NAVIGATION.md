# 导航组件约定

## 参考与范围

全站导航采用用户最终选定的 16:9 视觉方向：顶部主导航、模块二级导航、轻暖页面底、冷调近白表面与亮蓝选中态。视觉参考保存在 `docs/references/site-restructure-reference-16x9.png`，最终同尺寸结构对照保存在 `docs/references/site-reference-layout-comparison.png`。导航重构只改变信息架构和表现形式，不改变现有路由、权限或业务数据。

当前四个主模块为工作台、客户与报价、商品资料、系统设置。主导航切换模块；下方二级导航只显示当前模块的页面，避免侧栏同时展开多组层级。应用名称继续使用 Dashboard，图标使用 Tabler Icons，不引入品牌素材或整套 UI 库。

## 结构

- `src/components/navigation/TopNavigation.tsx`：桌面顶栏、模块导航、二级导航、功能搜索、账号菜单和移动端菜单。
- `src/components/navigation/top-navigation.css`：顶部导航的尺寸、响应式和交互状态。
- `src/components/navigation/types.ts`：分区、分组、链接类型。
- `src/config/navigation.ts`：唯一菜单配置入口。
- `src/components/layout/AppLayout.tsx`：按角色过滤菜单并组合顶部导航与路由内容。
- `src/theme.css`：全站色板和跨模块视觉令牌。

## 配置与路由

`NavigationSection` 内的顶级 `group` 对应主导航模块；其 `children` 对应二级导航：

- 工作台：保留首页 `/` 快捷入口。
- 客户与报价：首页 `/`、客户项目 `/customers`、报价模板 `/quotes/templates`；首页按参考图归入该模块并显示该组二级导航。
- 商品资料：SKU 档案 `/skus`、商品基础字典 `/sku-foundation`。
- 系统设置：配置中心字典 `/settings/dictionaries`、账号管理 `/settings/accounts`。

点击主模块进入其首个子路由。账号管理仅管理员显示；过滤后没有可见子项的模块不显示。新增页面时应同步路由、配置和架构文档，不创建指向空页面的菜单。

## 视觉

- 主导航连分隔线高 62px，二级导航连底部分隔线共 51px；页面内容从固定的 113px 导航高度之后开始。
- 页面底色使用参考图中的轻暖骨白 `#f5f3f0`，导航和内容表面使用冷调近白 `#fefdfc`，正文使用蓝黑 `#0d1630`，辅助文字使用蓝灰 `#6a7993`。
- 主操作和当前导航使用参考图亮蓝 `#0047c3`，深色交互态使用 `#00399d`，浅选中面使用 `#eaf2ff`；边框使用冷灰 `#dce1e7`，避免上一版偏黄褐的分隔效果。
- 当前主模块和二级页面都以细蓝色下划线表达，不使用大面积蓝色填充。
- 桌面端顶部搜索保留参考图的快捷键提示，并显示帮助、通知和账号区；中等宽度下优先隐藏辅助工具，窄屏再收起主导航，避免横向溢出。
- 内容模块优先使用留白、对齐和细分隔线；仅独立业务面板使用 6–10px 圆角，避免卡片套卡片和重阴影。
- 客户模块保留看板 + 详情结构，报价保留模板列表 + 明细结构，字典保留分组 + 表格结构；视觉令牌一致但业务布局不强行相同。

## 搜索、账号和移动端

- 顶部搜索只搜索当前已授权可见的功能入口；输入关键字后可点击或回车进入首个匹配路由，不搜索业务数据库。
- 账号菜单显示当前账号和角色，退出操作复用已有服务端会话注销。
- 760px 以下主导航收进菜单按钮，二级导航横向滚动；业务页面继续使用各模块现有的窄屏规则。
- 当前路由由 `NavLink` 输出 `aria-current`；菜单按钮、搜索和账号菜单保留键盘焦点样式。

## 扩展边界

导航不承担权限判定，服务端仍独立校验每个 API。顶部功能搜索不替代客户、SKU 或模板页面内的业务搜索。首页只展示真实接口数据和明确空状态，不用虚构指标填充视觉。视觉检查记录见仓库根目录 `design-qa.md`。
